# Memory Game

Игра «Memory»: на поле 16 закрытых карточек (8 пар). Открывайте по две карточки за ход и найдите все пары за как можно меньшее число ходов.

**Деплой:** https://ileshchanka.github.io/memory-game/

## Возможности

- Карточки перемешиваются (Fisher–Yates) при загрузке страницы и в каждой новой игре.
- Совпавшая пара остаётся открытой, несовпавшая закрывается через 1 секунду. Пока она не закрылась, другие карточки выбрать нельзя.
- Счётчики ходов и найденных пар (`0/8`).
- Модальное окно победы с количеством ходов.
- Лидерборд: топ-10 завершённых игр в `localStorage` (меньше ходов выше, при равенстве выше более ранняя игра), дата в формате `DD.MM.YYYY`.
- Модальные окна закрываются кнопкой, кликом по фону или клавишей `Escape`.
- «Новая игра» сбрасывает поле и счётчики без перезагрузки страницы.

## Технологии

Чистые HTML, CSS и JavaScript (ES-модули), без библиотек. Вся разметка создаётся через `document.createElement` (обёртка `el` в `src/dom.js`). В исходном `<body>` есть только `<script>`.

## Структура

```
index.html          — точка входа
styles/style.css    — стили
src/main.js         — сборка приложения
src/game.js         — логика игры
src/ui.js           — хедер, счётчики, таблица лидерборда
src/modal.js        — общее модальное окно
src/storage.js      — работа с localStorage
src/shuffle.js      — перемешивание Fisher–Yates
src/dom.js          — обёртка над document.createElement
```

## Локальный запуск

ES-модули не загружаются по протоколу `file://`, поэтому нужен локальный сервер:

```bash
git clone https://github.com/ileshchanka/memory-game.git
cd memory-game
git checkout memory-game
npx serve .
```

Затем откройте адрес, который выведет `serve` (по умолчанию http://localhost:3000). Подойдёт и Live Server в VS Code / встроенный сервер WebStorm, либо `python3 -m http.server`.
